# zerotrustiap 😎🕵️‍♀️
zerotrustiap : | Zero-Trust | Identity Aware Proxy (IAP), App Engine, Securing Cloud Applications | 


## Objectives
- To deploy simple App Engine application using Python.
- To enable Identity Aware Proxy (IAP) & restrict access to the app.
- To obtain user identity information from IAP in the app.
